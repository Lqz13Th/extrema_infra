# Discussion benchmark evidence

This directory contains the source reconstruction material and retained raw
results for two benchmark-backed Extrema Infra Discussions prepared on
2026-08-06:

- `ws-decoding-0.3.1/`: the release-exact four-exchange WebSocket decoder A/B.
- `three-framework-comparison/`: the Extrema Infra, Barter-rs, and
  NautilusTrader zero-network comparison.

Each subdirectory has its own provenance, reconstruction, scope, and
limitations. Generated build output such as Cargo `target/` directories is
intentionally excluded.
